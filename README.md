# La Clinic by Gislaine Freitas

Site institucional premium para clínica de estética avançada em Mariana, MG.

## Objetivo
Criar uma experiência digital sofisticada, com foco em identidade visual, confiança e agendamentos via WhatsApp.

## Etapa atual
Planejamento de marca e copywriting.

## Desenvolvimento
Astro, Tailwind CSS e GSAP (etapa futura).
